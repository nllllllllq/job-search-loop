# V1.1–V1.2 录入效率、紧凑 UI 与稳定性加固设计

日期：2026-07-28  
基线：`master` 合并 Desktop V1 后的提交 `947ac99`

## 目标

这一轮把现有“功能完整但录入和浏览偏重”的桌面版改造成更紧凑的个人求职工作台，并完成 V1 已记录的数据、审核和备份加固。

V1.1 交付数据加固、紧凑信息架构、离线截图 OCR、多项目文件导入和备份恢复加固。V1.2 交付公开岗位链接解析、性能基线和 Windows 发布验收。

## 产品边界

- 导入功能不调用外部生成式 AI。离线 OCR 只在本机运行。
- 岗位不保存来源链接，不保存结构化 JD。
- 原始截图和项目文件不复制、不持久化，也不进入备份。
- 所有识别结果先预览、编辑并由用户确认；导入服务不能直接写数据库。
- 公开链接只解析无需登录的公网 HTTPS 静态内容。
- 代码签名证书和两套干净 Windows 环境是发布门槛，不阻塞本地实现和测试完成。

## 信息架构

主导航为总览、岗位、项目档案、问题库、随想心得、设置。复盘中心和能力主题移入总览右侧抽屉；旧路由跳转到总览并打开对应抽屉。

岗位详情改为单页紧凑布局：顶部显示公司、岗位、位置、兴趣度和当前阶段；正文首先展示完整 JD；标准流程横向排列并最多折成两行；准备材料和面试记录在同页下方展示最新记录并可展开历史。

新岗位自动具有标准流程。节点点击后直接编辑日期、反馈和备注，自定义节点放入“更多流程设置”。

## 数据模型

- `positions.location TEXT NOT NULL DEFAULT ''`
- `projects.unclassified_notes TEXT NOT NULL DEFAULT ''`
- 新表 `capability_analysis_runs`：保存所选岗位 ID、Prompt、Provider origin、模型、输入 JSON、输出 JSON和创建时间。
- `change_proposals.analysis_run_id` 可空引用分析批次。
- 面试审计状态在 DTO 中表现为 `none | valid | invalid`。
- 建议列表 DTO 包含最小岗位与面试上下文，不包含原始 JD、面试文字或审计快照。

旧数据库和旧备份迁移后使用空位置、空待整理内容，不修改既有事实、资产、版本或审计快照。

## 本地导入

### 岗位

统一录入面板包含手动、粘贴文本、截图和公开链接。

截图支持最多 10 张 PNG/JPG，单张不超过 12 MB，总像素不超过 40MP。图片按用户排列顺序 OCR 后合并。规则匹配公司、岗位、位置和完整 JD；兴趣度默认 3。低置信字段显示警告，但始终允许用户修正。

### 项目

支持不超过 25 MB 的 DOCX、PDF、TXT、MD；PDF 最多 100 页，单次最多提出 30 个项目段。DOCX 只提取标题和纯文本，PDF 优先提取文本，扫描 PDF 回退本地 OCR。

用户先确认项目分段，可改名、合并、拆分、排序或取消选择，再确认背景、目标、角色、关键决策、结果、证据、反思、讲述版本和待整理内容。

### 链接

主进程仅抓取公网 HTTPS；禁止凭据、本机、私网、保留地址、DNS 重绑定和跨协议重定向。超时 10 秒，最多 3 次重定向，响应最大 3 MB，不执行页面脚本。

解析顺序为 `JobPosting` JSON-LD、页面标题与字段、静态正文规则。失败时引导使用截图或粘贴，不保存 URL。

## 稳定性加固

- 已复盘面试在数据库层锁定。
- 坏复盘快照和坏建议逐条隔离，坏建议不可操作。
- 四类建议默认使用字段化编辑表单，JSON 仅为高级视图。
- 修复建议上下文 N+1、Preview Token 异常清理、操作失败提示、防重复提交和 merge 等价判断。
- 共性能力分析以批次事务保存审计快照和全部 pending 建议。
- 恢复操作写入外部事务标记；启动时可继续恢复、使用回滚副本或保留现场。
- 回滚副本默认保留最近 3 份，可校验并由用户确认删除。
- 备份支持进度、原子替换前取消和可选 `integrity_check`。

## 验收

- 1024×700 下导航、抽屉、表单和弹窗无关键遮挡。
- 岗位截图、项目文档和公开链接均只生成预览，不直接写库。
- 混合好坏审计数据时，好记录仍可查看和操作。
- 2,000 个岗位、500 条建议、200 份准备历史下不存在 N+1 查询。
- OCR 语言数据、WASM 和文档解析依赖随安装包提供，断网可使用截图和文件导入。
- 全量单测、类型检查、生产构建、构建产物测试、Electron E2E 和 Windows smoke 通过。
- 发布前闭环 E2E 连续运行 20 次并保留失败诊断。
