# 求职闭环

求职闭环是一款本地优先的 Windows 求职规划工具。它不改简历、不自动投递，也不创建待办；它把岗位、流程日期、准备材料、面试复盘、项目、问题、能力和心得串成一条可回看的个人闭环。

## V1.1 主要功能

- 岗位：保存公司、岗位名称、位置、兴趣度与完整原始 JD；新岗位自动带有标准流程，可直接记录实际日期、预计日期、反馈与备注。
- 高效录入：支持手动填写、粘贴岗位文本后预填，以及 PNG/JPG 截图的离线中英文 OCR。所有识别结果都要由用户确认后才保存。
- 项目档案：支持手动维护，也可导入 DOCX、文本型 PDF、TXT、MD；先确认项目分段，再核对背景、目标、角色、决策、结果、证据、反思、讲述版本和待整理内容。
- 总览：查看岗位和流程摘要，并从右侧抽屉处理待确认建议、查看与维护能力主题。
- 问题库与随想心得：沉淀面试问题、候选人反问和可复用经验。
- AI 准备与复盘：仅在用户查看发送摘要并确认后调用自己配置的 OpenAI-compatible API。
- 本地备份：导出 `.jobloop`，支持校验、恢复、恢复中断处理和最近三份回滚副本。

V1.1 没有岗位链接录入或抓取入口。公开链接解析不在当前范围内；请使用粘贴文本或截图录入。

## 安装与启动

运行 `JobSearchLoop-Setup-1.1.0.exe`，按向导选择安装目录。也可以直接运行免安装目录中的 `win-unpacked\求职闭环.exe`。

当前个人使用版未进行商业代码签名，Windows 可能显示来源提醒；请只使用自己构建或可信来源提供的安装包。

### 本地开发

需要 Node.js 24+ 与 npm。

```powershell
npm install
npm run dev
```

常用验证命令：

```powershell
npm test
npm run typecheck
npm run build
npm run test:build-output
npm run test:e2e
npm run smoke:ocr
npm run package:win
npm run smoke:win
```

- `npm run test:e2e`：在真实 Electron 中运行核心闭环和本地导入主路径，不访问外网。
- `npm run smoke:ocr`：验证构建后的中英文离线语言数据，并运行一次本地 OCR。
- `npm run package:win`：在 `release/` 生成 x64 NSIS 安装包和 `win-unpacked/`。
- `npm run smoke:win`：启动 unpacked 应用，检查窗口、数据库创建和生产 DevTools 状态。

## 本地数据与隐私

Windows 安装版的数据目录通常是：

```text
%APPDATA%\求职闭环\
```

核心记录保存在 `job-search-loop.sqlite`。AI 地址、模型和加密后的 API Key 保存在独立配置文件中，不会进入 `.jobloop` 备份。

- 岗位截图、OCR 中间文本和导入的项目原文件只存在于本次内存预览；确认、取消或超时后释放，不写入数据库和备份。
- 截图 OCR 使用安装包内的 `eng` 与 `chi_sim` 数据，识别过程不下载、不外发。
- DOCX 仅提取纯文本；PDF 仅提取可用文本；页面不会注入文档 HTML。
- 应用没有遥测，也不会自动调用 AI。

以下操作只有在用户确认发送摘要后才会调用外部 AI：

- 根据岗位原始 JD 和主动选择的项目、问题生成准备材料。
- 根据岗位、面试文字和主动选择的长期资产生成复盘建议。
- 根据用户明确选择的多个 JD 分析共性能力。

AI 输出先在本机校验。复盘和能力建议必须由用户在待确认抽屉中接受，才会写入长期资产。

## 配置 OpenAI-compatible API

在“设置”中填写 API 地址、模型和 API Key。远程服务必须使用 HTTPS；本机调试可使用 localhost。不同服务商的数据政策不同，发送前请确认所选服务的隐私说明。

## 备份与恢复

在“设置 → 本地备份”中：

- “导出本地备份”创建 `.jobloop`，不包含 AI 配置或 API Key。
- “恢复本地备份”先校验文件和数据库版本，再创建当前数据库的回滚副本并替换数据。
- 若替换过程中断，重新启动后可继续恢复、使用回滚副本或保留现场。
- 设置页可查看最近的回滚副本；默认保留最近三份。
- 可选深度完整性校验；进入原子替换阶段后恢复不可取消。

恢复会替换当前本地记录，请先导出当前备份。

## 当前已知延期

这些项目不影响 V1.1 的主要使用流程，留待后续版本：

- 扫描型 PDF 自动逐页 OCR；当前请把相关页面导出为截图后使用岗位截图识别，或转成带文本的文档。
- 截图从系统剪贴板直接粘贴、拖放导入；当前使用文件选择。
- 旧版本遗留、仍待确认的能力合并建议的少见冲突处理。
- 商业代码签名和两套干净 Windows 环境的安装、升级、卸载验收。
- 手机 App、电脑与手机同步、录音转写、日历、待办和提醒。

不计划加入岗位来源字段、结构化 JD、自动投递或公开岗位链接抓取。
