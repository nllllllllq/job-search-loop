# V1.1 快速交付状态

## 当前执行原则

先完成可运行的核心闭环，再集中处理影响主要使用路径的问题。只保留必要的单元/界面测试、类型检查、生产构建、一次 Electron E2E 和 Windows unpacked smoke，不做极限性能、20 次循环或穷举故障矩阵。

## 已完成

- V1 基线合并到 `master`，V0.1 安装包已留档。
- 数据库 V5：岗位位置、项目待整理内容、能力分析批次审计和建议关联。
- 已复盘面试锁定、损坏复盘/建议隔离、最小建议上下文。
- 六项导航、总览待确认抽屉、能力抽屉和四类字段化建议表单。
- 能力主路径合并：现有问题、心得、证据和子能力关系迁移。
- 可恢复备份主路径：恢复事务标记、启动继续/回滚/保留现场、进度与替换前取消、最近 3 份回滚副本和可选深度校验。
- 紧凑岗位详情、位置搜索、新岗位标准流程和同页 JD/准备材料/面试记录。
- 手动、粘贴文本、离线截图 OCR 三种岗位录入方式；没有链接入口。
- DOCX、文本 PDF、TXT、MD 项目文件导入、项目分段确认和待整理内容。
- 离线 OCR 资源构建校验、核心导入 Electron E2E 与 Windows 本地发布验收。

## 本轮明确不做

- 公开 HTTPS 岗位链接解析；产品内也不保留链接识别入口。
- 极限性能基准、20 次连续 E2E 和完整故障注入矩阵。

## 后续版本处理

- 合并前生成、仍待确认的旧能力建议如何归一或标记冲突。
- 能力批量合并时每个被迁移资产的完整版本快照。
- V2/V3 等更早备份、故障注入矩阵和磁盘/文件锁异常。
- 恢复各替换阶段杀进程、只读目录、空间不足、目标盘断开和回滚副本损坏的组合测试。
- OCR 极端低清、多图像素上限、超时和所有取消竞态。
- 扫描 PDF 页面 OCR、截图剪贴板/拖放。
- 两套干净 Windows 的安装、升级、卸载验收和代码签名。
