# V1.6 首页、项目、岗位初始阶段与邮箱同步实施计划

## 执行原则

先完成功能再完美：每项只补一条最小可运行主路径测试；集中到最后跑全量测试、类型检查、生产构建和安装包。极限文档、邮件洪峰、复杂 IMAP 断线矩阵留到试用后决定。

## Task 1：岗位录入初始阶段与标准名称

- 新增创建岗位专用输入类型和 schema，保留岗位编辑接口兼容。
- 录入面板添加当前阶段与固定日期字段，默认已投递/今天。
- repository 原子生成流程并刷新 currentStage。
- StageEditor 标准名称自动填充，首次编辑自动名称时清空。
- 聚焦验证岗位创建、五种阶段中的代表路径、名称自动填充和现有日期策略。

## Task 2：首页、项目横条与快速心得

- AppShell 将“总览”改为“首页”。
- Dashboard 把待完成安排移动到统计区正下方。
- ProjectsPage 改为全宽横条列表和下方详情，展示简短介绍。
- 新建 QuickInsightButton，复用 `assets.insights.save`，只提交自动标题、正文和空关联。
- 聚焦验证导航标题、首屏顺序、项目选择和快速心得保存。

## Task 3：AI 通用修复和项目导入痕迹

- 统一 Chat/Responses JSON fence 清理。
- 连接诊断覆盖 Chat 与 Responses Web Search。
- 细化项目导入 Prompt，并仅对仍等于旧默认模板的记录自动升级，保留用户自定义模板。
- 项目导入 AI 失败返回安全诊断并继续本地回退。
- 项目确认页展示原文删除线和 AI 建议高亮；增加粘贴文本入口复用现有导入流程。
- 修复 fake AI provider 与准备材料 E2E 的旧契约。
- 使用脱敏/fixture 简历文本跑项目解析自动测试；真实简历只做本地解析，外发测试等待明确许可。

## Task 4：本地 IMAP 自动同步

- 增加 `imapflow` 与 `mailparser` 依赖。
- 新增加密邮箱设置仓库、窄 IPC、preload API 和设置手风琴。
- 新增邮件同步事件表及 repository；按 message id 去重。
- 新增只读 IMAP service、招聘状态规则和唯一岗位匹配。
- 应用启动同步一次并按设置轮询；提供立即同步与状态显示。
- 聚焦验证设置加密、规则匹配、去重、流程日期更新和手动同步。网络层使用 fake IMAP/注入 client，不访问真实邮箱。

## Task 5：Sol 验收与发布

- 检查全部变更和文件范围，确认未覆盖既有 V1.5.1 未提交补丁。
- 运行聚焦测试、全量测试、typecheck、build、Electron E2E 主路径。
- 更新 CHANGELOG 与版本号到 1.6.0。
- 仅保留最新安装包，重新生成 Windows 安装包并核对产物版本。
- 记录未完成的真实外部 AI/真实邮箱授权测试和试用后边界清单。
