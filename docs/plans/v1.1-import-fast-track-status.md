# V1.1 本地导入快速交付状态

## 本轮已完成的主路径

- 岗位统一录入面板：手动、粘贴文本、截图和本地预览确认；不保留公开链接入口。
- 文本与截图只生成预填表单，兴趣度默认 3，最终仍由现有岗位保存接口写入。
- Tesseract.js 使用安装包内 `eng`、`chi_sim` 数据，不配置任何运行时网络回退。
- DOCX、文本型 PDF、TXT、MD 的本地纯文本提取；Mammoth 生成内容只在主进程转为纯文本，不注入页面。
- 项目分段确认、改名、相邻合并、按空行拆分、排序、取消，以及字段预填和待整理内容。
- 项目逐条保存；中途失败时只保留未成功项目，重试不会重复创建已成功项目。
- 导入原图和原文件不写数据库；预览只存在带 TTL 的内存会话，确认、取消或过期后释放。

## 按“先完成核心、后补边界”延期

- 扫描 PDF 页面渲染后 OCR：当前明确提示改用截图导入。
- OCR 识别中的即时中断与细粒度百分比事件：当前识别在 Tesseract worker 中执行，界面显示处理中并在结果后支持取消预览。
- 拖放和直接读取系统剪贴板图片：当前支持文件选择、多图顺序调整；粘贴板和拖放交互后补。
- 低清、旋转、超长图以及 10 图/40MP 极限组合的完整矩阵。
- 扫描 PDF 回退和 Windows 双环境验收。

## 已执行的最小验证

- 文本岗位字段规则、双图有序 OCR（mock worker）、会话取消/过期。
- TXT、MD、DOCX、文本 PDF 提取主路径。
- 项目分段、合并、拆分、排序和待整理内容。
- 文本岗位确认保存、项目批量失败续存。
- 真实 Tesseract worker 加载本地中英文语言数据并识别本地生成图片。
- Electron 主路径覆盖粘贴岗位录入和 TXT 项目导入。
- Windows 构建产物包含离线 OCR 资源，并完成 unpacked smoke。
